Manual completo para utilizar todas las funcionalidades del sistema

Dashboard

Panel principal con estadísticas en tiempo real del servidor FTP

Estadísticas del Sistema

Estado del Servidor: Indica si el servidor FTP está en línea o fuera de línea.

Videos Almacenados: Número total de archivos de video en el sistema.

Espacio Utilizado: Cantidad de espacio en disco ocupado por los videos.

Uso del Disco: Porcentaje de uso del disco duro.

Última Subida: Fecha y hora del último video recibido.

Conexiones: Número de conexiones FTP activas.

Tiempo de Funcionamiento: Tiempo que lleva ejecutándose el servidor.

CPU y Memoria: Uso actual de recursos del sistema.

Actualización Automática

El sistema verifica automáticamente si hay actualizaciones disponibles en el repositorio Git.

Cómo funciona:

  • Se muestra una notificación cuando hay actualizaciones disponibles
  • Haz clic en "Actualizar ahora" para aplicar los cambios
  • El servidor se reiniciará automáticamente después de la actualización
  • Los cambios se registran en el changelog del sistema

Videos Recientes

Tabla que muestra los últimos 10 videos recibidos por el servidor FTP.

Información mostrada:

  • Fecha/Hora: Cuándo se recibió el archivo
  • Archivo: Nombre del archivo de video
  • Tamaño: Tamaño del archivo en MB

Gestión de Videos

Organización y acceso a todos los videos almacenados en el servidor

Biblioteca de Grabaciones

Vista principal que muestra todas las carpetas de videos organizadas por cámaras o ubicaciones.

Funcionalidades:

  • Búsqueda: Usa la barra de búsqueda para encontrar carpetas específicas
  • Actualizar: Botón para refrescar la lista de carpetas
  • Contador de Videos: Cada carpeta muestra cuántos videos contiene
  • Estadísticas: Resumen del total de carpetas y videos

Gestión de Alias

Sistema para asignar nombres descriptivos a las carpetas de videos.

Cómo usar:

  1. Haz clic en el icono de edición en cualquier carpeta
  2. Escribe un nombre descriptivo (ej: "Cámara Entrada Principal")
  3. Presiona Enter o haz clic en "Guardar"
  4. El alias se mostrará en lugar del nombre original de la carpeta

Atajos de teclado:

  • Enter: Guardar cambios
  • Escape: Cancelar edición

Vista de Videos por Carpeta

Al hacer clic en una carpeta, accedes a la lista detallada de todos sus videos.

Información mostrada:

  • Nombre del archivo: Nombre original del video
  • Fecha y hora: Cuándo se grabó o recibió
  • Tamaño: Tamaño del archivo
  • Duración: Tiempo de duración del video (si está disponible)

Acciones disponibles:

  • Reproducir: Ver el video en el reproductor integrado
  • Descargar: Descargar el archivo a tu computadora
  • Filtrar: Buscar videos específicos por nombre o fecha

Reproductor de Videos

Reproductor avanzado con soporte para archivos DAV y conversión automática

Reproducción Básica

El reproductor soporta múltiples formatos de video:

  • MP4: Reproducción directa e inmediata
  • AVI: Reproducción directa
  • DAV: Conversión automática a MP4 antes de reproducir

Controles disponibles:

  • Play/Pausa: Controlar la reproducción
  • Barra de progreso: Navegar por el video
  • Control de volumen: Ajustar el audio
  • Pantalla completa: Ver en pantalla completa

Conversión DAV a MP4

Los archivos DAV (formato propietario de Dahua) se convierten automáticamente:

Proceso de conversión:

  1. Al hacer clic en "Reproducir" en un archivo DAV, se inicia la conversión
  2. Se muestra una pantalla de "Preparando video..."
  3. La conversión se realiza en segundo plano
  4. Una vez completada, el video se reproduce automáticamente

Configuración de conversión:

  • Método: Software, NVIDIA, AMD, Intel o automático
  • Calidad: Configurable mediante CRF (18-28)
  • Resolución: Original, 1080p, 720p, 480p
  • Audio: AAC, MP3 o copia directa

Atajos de Teclado

Controles rápidos para una mejor experiencia:

  • Espacio: Play/Pausa
  • F: Pantalla completa
  • M: Silenciar/Activar audio
  • R: Reiniciar video
  • ← →: Retroceder/Avanzar 10 segundos
  • ↑ ↓: Subir/Bajar volumen

Funciones Avanzadas

Control de velocidad:

  • Botón de velocidad para cambiar entre 0.5x, 1x, 1.25x, 1.5x, 2x
  • Colores diferentes para cada velocidad

Información del video:

  • Duración: Tiempo total del video
  • Resolución: Dimensiones del video
  • Tamaño estimado: Tamaño aproximado del archivo

Descarga directa:

  • Botón de descarga para guardar el video original
  • Funciona tanto para archivos originales como convertidos

Sistema de Logs

Monitoreo y diagnóstico del servidor FTP

Visualización de Logs

Los logs muestran toda la actividad del servidor FTP en tiempo real.

Tipos de eventos registrados:

  • Conexiones: Intentos de conexión exitosos y fallidos
  • Transferencias: Subida y descarga de archivos
  • Errores: Problemas del sistema y errores de conexión
  • Seguridad: Intentos de acceso no autorizados
  • Sistema: Inicio, parada y configuración del servidor

Filtrado de Logs

Sistema de filtros para encontrar información específica:

Filtros disponibles:

  • Todos los niveles: Muestra todos los eventos
  • INFO: Solo eventos informativos
  • WARNING: Solo advertencias
  • ERROR: Solo errores críticos

Colores de identificación:

  • Azul: Eventos informativos (INFO)
  • Amarillo: Advertencias (WARNING)
  • Rojo: Errores (ERROR)

Actualización Automática

Los logs se actualizan automáticamente para mostrar la actividad más reciente.

Funcionalidades:

  • Auto-refresh: Actualización cada 30 segundos
  • Actualización manual: Botón "Actualizar" para refresh inmediato
  • Últimas 200 líneas: Se muestran los eventos más recientes

Interpretación de logs:

  • Cada línea incluye timestamp, nivel y descripción del evento
  • Los errores de conexión pueden indicar problemas de red
  • Los intentos fallidos repetidos pueden indicar ataques

Configuración del Sistema

Personalización completa del servidor FTP y sus funcionalidades

Configuración del Servidor FTP

Host/IP del Servidor: Dirección donde escuchará el servidor (0.0.0.0 para todas las interfaces)

Puerto FTP: Puerto de conexión (por defecto 60000, evita el 21 estándar)

Conexiones Máximas: Límite de conexiones simultáneas (recomendado: 256)

Conexiones por IP: Límite por dirección IP para evitar abuso (recomendado: 5)

Importante: Después de cambiar estos valores, reinicia el servidor para aplicar los cambios.

Configuración de Seguridad

Intentos Máximos: Número de intentos fallidos antes de bloquear una IP

Duración del Bloqueo: Tiempo en segundos que permanece bloqueada una IP

Registro de Intentos:

  • Deshabilitado: No registra intentos de conexión
  • Solo errores: Registra únicamente intentos fallidos
  • Todos los intentos: Registra todos los intentos (exitosos y fallidos)

Recomendaciones:

  • Mantén los intentos máximos entre 3-5
  • Duración de bloqueo de 5-10 minutos (300-600 segundos)
  • Habilita el registro para monitorear ataques

Gestión de Archivos

Directorio de Videos: Carpeta donde se almacenan los videos recibidos

Directorio de Logs: Carpeta para archivos de registro del sistema

Días de Retención: Tiempo que se mantienen los archivos antes de eliminarlos automáticamente

Archivo de Alias: Ubicación del archivo JSON con los nombres personalizados de carpetas

Consejos:

  • Usa rutas absolutas o relativas al directorio del proyecto
  • Asegúrate de que las carpetas tengan permisos de escritura
  • Configura la retención según tu espacio disponible

Interfaz Web

Host Web: Dirección IP para acceder a la interfaz (0.0.0.0 para acceso desde cualquier IP)

Puerto Web: Puerto para la interfaz web (por defecto 5000)

Configuraciones comunes:

  • Solo local: Host: 127.0.0.1, Puerto: 5000
  • Red local: Host: 0.0.0.0, Puerto: 5000
  • Puerto personalizado: Cualquier puerto libre (ej: 8080)

Conversión de Videos

Conversión DAV a MP4: Habilita/deshabilita la conversión automática

Método de Conversión:

  • Software: Usa CPU (compatible con todos los sistemas)
  • NVIDIA: Aceleración por GPU NVIDIA (requiere drivers)
  • AMD: Aceleración por GPU AMD
  • Intel: Aceleración Intel Quick Sync
  • Auto: Detecta automáticamente la mejor opción

Configuración de Calidad:

  • Preset: Velocidad vs calidad (fast recomendado)
  • CRF: Calidad (18=excelente, 23=buena, 28=aceptable)
  • Resolución: Mantener original o reducir para ahorrar espacio

Configuración de Audio:

  • AAC: Mejor compatibilidad
  • MP3: Mayor compatibilidad
  • Copy: Mantener audio original (más rápido)

Guardar y Restablecer

Guardar Configuración:

  • Los cambios se guardan inmediatamente en el archivo config.json
  • Algunos cambios requieren reiniciar el servidor
  • Se muestra una confirmación cuando se guarda correctamente

Restablecer Configuración:

  • Vuelve a los valores por defecto del sistema
  • Útil si hay problemas con la configuración actual
  • Se requiere confirmación antes de restablecer

Validación:

  • Los campos se validan en tiempo real
  • Los valores fuera de rango se marcan en rojo
  • Se muestran advertencias para configuraciones potencialmente problemáticas

Seguridad y Acceso

Información sobre el sistema de autenticación y seguridad

Sistema de Login

El sistema utiliza las mismas credenciales del servidor FTP para el acceso web.

Proceso de autenticación:

  1. Ingresa tu usuario y contraseña del servidor FTP
  2. El sistema verifica las credenciales contra el servidor FTP
  3. Si son correctas, se crea una sesión web
  4. La sesión permanece activa hasta que cierres sesión o expire

Credenciales por defecto:

  • Usuario: admin
  • Contraseña: admin123

Importante: Cambia las credenciales por defecto por seguridad.

Protección de Sesiones

Todas las páginas (excepto login) requieren autenticación activa.

Características de seguridad:

  • Sesiones seguras: Cada sesión tiene un token único
  • Timeout automático: Las sesiones expiran por inactividad
  • Logout seguro: Limpia completamente la sesión
  • Protección CSRF: Previene ataques de falsificación

Buenas prácticas:

  • Cierra sesión cuando termines de usar el sistema
  • No compartas las credenciales de acceso
  • Accede solo desde redes confiables

Sistema Anti-Brute Force

Protección automática contra ataques de fuerza bruta en el servidor FTP.

Cómo funciona:

  • Monitorea intentos de login fallidos por IP
  • Bloquea automáticamente IPs con muchos intentos fallidos
  • El bloqueo es temporal (configurable)
  • Se registran todos los intentos sospechosos

Configuración recomendada:

  • Intentos máximos: 3-5 intentos
  • Tiempo de bloqueo: 5-15 minutos
  • Logging: Habilitado para monitoreo

Monitoreo de Actividad

El sistema registra toda la actividad para auditoría y seguridad.

Eventos monitoreados:

  • Logins web: Accesos exitosos y fallidos a la interfaz
  • Conexiones FTP: Todas las conexiones al servidor
  • Transferencias: Subida y descarga de archivos
  • Cambios de configuración: Modificaciones del sistema
  • Errores del sistema: Problemas técnicos

Revisión de logs:

  • Revisa regularmente los logs en la sección "Logs"
  • Busca patrones sospechosos o errores recurrentes
  • Los intentos de acceso no autorizados aparecen como errores

Solución de Problemas Comunes

Guía para resolver los problemas más frecuentes

Problemas de Conexión

El servidor aparece como "Fuera de línea":

  • Verifica que el servidor FTP esté ejecutándose
  • Comprueba que el puerto configurado esté libre
  • Revisa la configuración de firewall
  • Verifica las credenciales de acceso

No puedo acceder desde otra computadora:

  • Configura el host web como "0.0.0.0"
  • Abre el puerto en el firewall
  • Verifica la conectividad de red

Problemas con Videos

Los videos DAV no se convierten:

  • Verifica que FFmpeg esté instalado
  • Comprueba la configuración de conversión
  • Revisa los logs para errores específicos
  • Prueba con el método "software" si hay problemas con aceleración

La conversión es muy lenta:

  • Usa aceleración por hardware si está disponible
  • Ajusta el preset a "fast" o "faster"
  • Reduce la resolución de salida
  • Aumenta el número de threads

Problemas de Espacio

Disco lleno o casi lleno:

  • Reduce los días de retención de archivos
  • Elimina manualmente videos antiguos
  • Configura una resolución menor para conversiones
  • Considera usar un disco externo para almacenamiento

Los archivos no se eliminan automáticamente:

  • Verifica la configuración de días de retención
  • Comprueba los permisos de la carpeta de videos
  • Revisa los logs para errores de eliminación

Reinicio y Recuperación

Cuándo reiniciar el servidor:

  • Después de cambiar la configuración del servidor FTP
  • Si hay problemas de memoria o rendimiento
  • Después de actualizar el sistema
  • Si los logs muestran errores persistentes

Recuperación de configuración:

  • Usa "Restablecer configuración" si hay problemas
  • Los archivos de configuración se guardan en config.json
  • Puedes editar manualmente el archivo si es necesario
